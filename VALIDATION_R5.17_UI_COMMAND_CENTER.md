- Asset 360 device-detail preview with General / Backup / Storage / Events / Identity visual tabs.

## Contract safety
These are additive presentation surfaces. Existing element IDs, forms, tables, data-section values and
JavaScript/backend contracts are preserved. No Agent, API, backup engine, restore engine, database,
repository format, MeshCentral protocol or authorization behavior is changed.
