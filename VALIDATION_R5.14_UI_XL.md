# VALIDATION_R5.14_UI_XL

## Scope
UI-only enterprise light redesign based on the supplied R5.13 UI package.

## Visual changes
- Sidebar widened to 304px and every navigation item converted to a large card-like control.
- Active navigation uses corporate blue gradient and stronger focus hierarchy.
- KPI cards increased to XL size with larger numbers and hover motion.
- Main module panels, quick actions, restore cards, pilot cards and guide cards enlarged.
- Topbar/search/avatar and page heading redesigned for a premium enterprise appearance.
- Light theme preserved throughout.
- Responsive rules retain usability at 1500px, 1250px, 960px and mobile breakpoints.
- Reduced-motion accessibility behavior remains supported.

## Safety
No API route, JavaScript ID, data-page attribute, form ID, runtime service, backup engine,
restore engine, database schema, MeshCentral connector or Agent behavior was changed.
