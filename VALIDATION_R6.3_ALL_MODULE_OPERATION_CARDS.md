# R6.3 — All Module Operation Cards

## Scope
UI-only Control Plane release based on R6.2.

## Result
Every major module receives a dedicated XL operation-card grid. Each card points to an existing real control or operational surface and scrolls/focuses the operator to that workflow.

Covered modules:
Dashboard, Pilot, Computers, Agent Lifecycle, Backup, Policies, Restore, Validation, Recovery, NAS/Storage, Alarms, MeshCentral, Users, Security, Audit, Settings.

No fake actions, fake telemetry, or duplicate backend behavior was introduced.

## Runtime
- R6.1 zero-touch Agent lifecycle preserved.
- R6.2 large-card foundation preserved.
- Agent binary unchanged.
- No PUBLISH_AGENT required for R6.3.
